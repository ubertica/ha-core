# ha-team-forge

Grok plugin for volume-building HA teams.

See SKILL.md in the skills copy and the canonical `~/.grok/skills/ha-team-forge/SKILL.md`.

Commands: ha-team-forge (dispatches forge).

Agents: forge-lead for workflow-driven forges.

Forge examples use lanes-*.json + templates under skill.

Gold patterns: ha-hackers, ha-pumapay, ha-sentinel.
